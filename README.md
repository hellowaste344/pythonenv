# Python Scripts Playground

Welcome 👋  
This repository contains a collection of independent Python scripts, each demonstrating the usage of different `pip` packages and libraries.

---

## 📦 What this repo is

Each script in this repository is a **self-contained example** of a specific library or tool.

Instead of maintaining a single `requirements.txt`, each script is designed to stand on its own. This allows you to:

- Explore libraries independently
- Avoid installing unnecessary dependencies
- Quickly test isolated functionality

---

## 🚀 Getting Started

You can run scripts using standard Python virtual environments.

---

## 🐍 Using Python venv 

```bash
python -m venv venv
source venv/bin/activate   # Linux / macOS
# venv\Scripts\activate    # Windows
```
